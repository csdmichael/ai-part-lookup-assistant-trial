# Requirements

Engineers often need information about a part but must search across multiple systems to find inventory levels, supplier details, purchase orders, and delivery dates. This process is time-consuming and delays decision-making.

Build a working tutorial application for AI Part Lookup Assistant. It should let users complete the main workflow from start to finish, review and update the information they need, and receive clear feedback for successful and unsuccessful actions. Use realistic sample data, validate user input, protect sensitive information, work on desktop and mobile screens, and include automated tests for the main workflow.
